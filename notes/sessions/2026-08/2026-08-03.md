## v0.29.0 — PLANT: Span (grow-a-beam-to-fit-a-gap)

**Trigger.** Scheduled PLANT run (`fairyfox-games-new`). One brand-new, mechanically-distinct game,
built to the full quality bar and released.

**The design — a genuinely new verb.** Walked the existing verb list (steer, time-a-catch, thrust,
flip-match, aim-bounce, precision-stack, keep-aloft, balance, mirror, judge-power/charge, pour/fill,
swing, weave, sort, guard, herd, recall, give-and-take) and picked one none of them cover:
**spanning/construction** — grow a length to fit a gap you can see. Verified `span`/`bridge`/`beam`
appear nowhere in `games/` or `notes/plans/`. Distinct-by-construction from the two nearest games:
it's not Arc's ballistic charge (outcome hidden while charging) and not Brim's metered pour (a lag
line) — the beam gives continuous spatial feedback and a miss is **two-sided** (short *or* over).

**The game.** Hold to grow a beam upright, release to drop it flat across the gap; land the tip on
the far ledge to cross. Land dead-centre on the **keystone** stone → the multiplier climbs (×2…×9);
a loose land scores but breaks it to ×1. The hidden tech is the **plumb** — a razor sub-window dead
through the exact centre, drawn nowhere; three plumbs in a row lock a **Truss** (double points ~5 s).
Three misses (short/over) end the run. Two no-plateau axes: beam grow speed rises and ledges shrink,
both smooth asymptotes.

**Build (copied Polarity's shape).** `games/span/`: pure `span.core.js` (`tick(g, holding)`-split,
no DOM/canvas/timers, injected seedable RNG, JSDoc'd); external `span.shell.js` module (canvas, the
one hold-to-grow input, fixed-timestep loop, the beam-drop/cross animation, global error +
unhandledrejection logging, guarded render loop); `index.html` (module load + classic-script boot
fallback showing a visible error); `package.json`; `README.md` (with a "How it grows" section).
Varied structure + progression from birth (6 `minStage`-gated formations: Steady · Reach · The
Bench=greed window · Stagger · The Narrows · The Gauntlet), a stage arc (Footbridge → … → Skyway) +
a secret **Firmament** stage, meta (`span.meta`, 15 badges, legacy `span.best`), and a **Lanterns**
coin fun mode (additive render only).

**Tests.** `span.core.test.js`, **34 tests** (`node --test`, zero deps): construction/reset, control
edges + frame-one safety, both difficulty asymptotes (with a no-plateau regression), resolve geometry
(short/land/over), keystone/plumb/Truss scoring, multiplier cap, lives + settle + death, the
varied-structure invariants (pool well-formed, stage-gated + deterministic pick, distinct seeds →
distinct structure, values in bounds, queue never empties), width-shrink at spawn, milestones, stages,
and the full meta layer. Game green, then the **whole collection 855/855** green (821 + 34).

**Wiring.** `_games/span.md` (tags **Bridging** · **Precision** — Bridging is a new verb-tag, the
established pattern for a new mechanic; the landing card, `/tags/` page and masthead count all
generate from it). Prepended a player-facing `kind:new` entry atop `_data/changelog.json`; `npm run
gen:readme` synced the README table (**19 games**). Rendered a bespoke 512×512 dark-neon `icon.png`
(fox glow + a cyan→magenta beam bridging two ledges with a warm centre stone) via the headless-Chrome
`--screenshot` pipeline (fresh `--user-data-dir`), eyeballed it, kept only the PNG.
