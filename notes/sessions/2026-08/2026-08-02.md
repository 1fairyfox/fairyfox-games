## v0.28.0 — PLANT: Reel — a give-and-take (resist/yield) game

**Trigger.** Scheduled PLANT (`fairyfox-games-new`) run. Job: ship one genuinely-new,
mechanically-distinct game to the full quality bar, released.

**Design.** Chose a verb not in the used list (steer / time-a-catch / thrust / flip-match /
aim-bounce / precision-stack / keep-aloft / balance / mirror / charge / pour / swing / recall /
guard / herd / weave / sort): **give-and-take** — resist vs. yield against a *reacting*
opponent. **Reel**: hold one control to reel a fighting catch; it alternates calm ↔ surge, and
reeling through a surge spikes line **tension** toward a **snap**. Fill progress to land it;
three snaps end the run. Deliberately distinct from Brim (Brim meters your own one-shot pour
with a fixed lag; Reel is a continuous read/modulate loop against an adversary's changing
state).

**Build (full quality bar, copied Polarity's architecture).**
- Pure `reel.core.js` — `tick(g, holding)` split, no DOM/canvas/timers, injected seedable RNG.
  Give-and-take physics (reel/rest, tension, snap, dive, landing), the hidden **haul** (reel
  in the razor window right after a surge *breaks* → bonus progress + ×2…×9 mult), **Frenzy**
  (3-haul streak → double points), a **no-plateau** `surgeTenseScale` asymptote, six stage-gated
  **temperaments** (Minnow · Steady · Darter · Sunfish=greed · Diver · The Leviathan) as a
  seeded segment schedule (every build starts calm → frame-one/refill guard), stages
  (Ripple→…→Maelstrom + secret **The Deep**), and the full meta layer (`reel.meta`, 13 badges,
  legacy `reel.best`).
- `reel.shell.js` — canvas render (the catch rises with progress, hot line + jitter on surge,
  right-edge tension meter with danger band, lives dots, haul sparks, Frenzy bloom), one
  **hold-to-reel** input (mouse/touch/Space), fixed-timestep loop, persistence, boot-failure
  fallback + guarded loop + global error logging, **Glimmer** coin fun mode (additive only).
- `reel.core.test.js` — **32 tests** (config/pool well-formed, frame-one safety, physics,
  snap/lives, haul + Frenzy, once-per-break, asymptote bounds, stages, varied-structure
  invariants incl. distinct-seeds→distinct-structure + queue-never-empties, meta reducer).

**Wire + log.** `_games/reel.md` (tags `[Tension, Timing]`, → landing card + count 17→18);
`gen:readme` synced the README table; prepended a `new` entry to `_data/changelog.json`.

## v0.27.4 — GROW: Tether · Windfall (a lifetime-milestone-gated formation)

**Trigger.** Scheduled EXPAND run. Both rollouts (varied structure 13/13, depth 12/13 +
plant-from-birth) are complete, so per the task the move is *add one new sub-pattern OR a
cross-run unlock* to the least-covered game. Picked **Tether** — the oldest untouched core
(modified 2026-07-11, unchanged since it was planted at v0.21.0).

**What I did — a cross-run unlock (varied-structure rule #3: the meta layer _driving_ variation).**
Added **Windfall**, a new anchor-line that is *absent from the pool until the player has banked
`UNLOCK_WHIPS` (150) whips across all their runs*, then appears in every deep run thereafter.

1. **Core.** New `buildWindfall` (a downhill plunge: anchors drop ceiling→floor of the sky,
   ropes shorten and arcs quicken — the mirror of the calm Rise). The formation carries an
   `unlock(meta)` predicate gating on lifetime whips (the *skill* act, so the reward tracks
   mastery, not survival — skill-safe). Two new pure exports: `unlockedFormations(cfg, meta)`
   (earned gated ids) and `newlyUnlockedFormations(prev, next, cfg)` (what to announce).
   `pickFormation` takes an optional `unlocked` set — **default none, so every prior call is
   byte-for-byte unchanged** and gated formations never leak into an unearned run.
   `createGame` seeds `g.unlocked` from `opts.meta`; `reset` never clears it (it's an account
   property, not a run one).
2. **Shell.** Passes `meta` into `createGame`, refreshes `game.unlocked` each `beginRun` (so a
   line earned last run shows up this one), and **leads the game-over badge list with a
   warm-accented "New line: Windfall" notice** the run it crosses the threshold (the announce
   requirement). `.badge.unlock` CSS accent added.
3. **Tests (+6, 32 → 38).** absent-until-earned; monotonic-and-not-free; `pickFormation`
   gating + determinism + `minStage` still holds even when unlocked; announce-once boundary;
   an unlocked Windfall still spawns only reachable/on-field anchors; `createGame` reads meta.

**Player-facing.** Prepended a `grow` entry to `_data/changelog.json`; bumped Tether's card
`updated` to 2026-08-02.
