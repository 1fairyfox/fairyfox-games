## v0.26.1 — GROW: Sluice depth — flash · Spate · no-plateau fall · secret Charybdis

**Why Sluice.** GROW run (`fairyfox-games-daily`). Varied-structure rollout is complete; the
active lever is the "depth inside the mechanic" layer. Sluice was the last game still named as
missing it (prior status: *depth rollout 11 of 13, left: Sluice*), so it was the clear pick.
The newer games (Tether/Reprise/Ward/Drove/Brim/Loom) already ship depth from birth; this
clears the retrofit list.

**What Sluice already had.** Varied structure (formations Steady/Run/Alternate/Shuffle/Cascade/
Rush/The Churn, `pickFormation`/`loadFormation`, `minStage`-gated), a stage arc (Trickle →
Maelstrom), a snap-combo (route within `SNAP_FRAC` of the fall grows the ×2…×9 multiplier),
and meta (`sluice.meta`, 10 badges). Missing: the four depth items.

**The four items (all on the one *route* verb):**

- **Flash — the hidden tech.** A route inside the razor **`FLASH_FRAC` 0.12** sub-window (well
  tighter than the `SNAP_FRAC` 0.45 snap) — reading a freshly-scrambled row and committing
  almost the instant the spark appears — pays a flat **`FLASH_BONUS` 2** on top of the snap,
  blooms gold, and builds a streak. Taught nowhere. A plain snap or a miss silently breaks the
  flash chain. (A flash is always also a snap, so it grows the multiplier too.) Fits Sluice's
  own hook exactly: the depth *was* "when you commit," so an even-earlier commit is the ceiling.
- **Spate — the streak reward.** `FLASH_STREAK` 3 flashes in a row → `SPATE_TICKS` 300 (~5s)
  where **every point doubles**. The triggering flash is *not* doubled — `doubling` reads
  `g.spate > 0` before the resolution scores, and the window is armed after. `tick` counts it
  down. Gold vignette (colour-only; static under reduced motion).
- **No-plateau fall asymptote.** `fallTicksOf` rewritten: `FALL_HARD_MIN 30 + (FALL_BASE 108 −
  FALL_HARD_MIN) · exp(−cleared / FALL_TAU 130)` — approaches but never reaches the floor, so
  late sparks keep quickening forever. Replaced the old linear `FALL_BASE − cleared·FALL_DEC`
  clamped at `FALL_MIN 40`, which flat-lined at cleared ≈ 136. Opening unchanged (cleared 0 =
  108). `spawnDrop` no longer clamps the non-fast path at 40 (that would re-introduce the
  plateau); fast sparks get a separate `FAST_MIN 22` floor.
- **Secret Charybdis stage.** STAGES gains a 6th entry (`at` 180, `secret: true`). `stageProgress`
  hides a secret *next* stage from the HUD (the bar still fills toward it, nameless) until you
  cross into it. Printed on no start screen; the start tip's stage ladder + formation-name list
  were trimmed (teach-by-play).

**Bookkeeping.** 3 new badges (10 → 13: `flash-hand` = 10 flashes/run, `spate` = raise one,
`charybdis` = reach the hidden stage), `totals.flashes` added to meta (lossless legacy upgrade),
run report names flashes/spates. Shell: gold flash channel overlay + Spate banner/vignette,
summary carries `flashes`/`spates`.

**Tests.** Rewrote the fall-time test for the asymptote (monotonic descent; never below the

age into the snap-but-not-flash band). Added flash/Spate tests (bonus, correct-only, streak

test functions; full collection **783/783** green (`node --test "games/**/*.test.js"`).
