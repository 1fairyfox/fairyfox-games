## v0.28.0 — 2026-08-02 — PLANT: Reel — a give-and-take (resist/yield) game

A new game, **Reel** — the collection's **18th** and a genuinely new verb: **give-and-take**
(resist vs. yield). There's a catch on the line that *fights back*. You hold **one** control
to reel it in; the catch alternates between **calm** (reel freely) and a **surge** (it
thrashes — reeling now spikes the line **tension**). Read the reacting opponent: pour on the
reel while it's calm, ease off the instant it fights. Fill the progress to **land** it; max
the tension and the line **snaps** (three snaps end the run). Distinct from everything we
have — not steering, timing, aiming, metering, swinging, remembering, guarding, herding,
weaving or sorting, but **modulating a sustained pull against a living, reacting force**
(Brim meters *your own* one-shot pour with a fixed lag; Reel is a continuous back-and-forth
with an adversary whose state you must keep reading).

Ships on **varied structure + the depth layer from day one**:
- **Depth = the haul (discovered, not told).** The tick a surge *breaks* opens a razor
  `HAUL_WIN` window — snap back onto the reel in that instant and the catch's spent lunge
  converts to a burst of progress + a growing multiplier (×2…×9). The safe instinct is to
  keep resting; the greedy line is to re-grab at the break — reel a hair too early (still
  mid-surge) and you over-tension toward a snap. Precise = greedy, on the one input.
- **Frenzy** — a 3-haul streak lights a ~5 s window where every point doubles (the trigger
  never doubled).
- **No plateau** — `surgeTenseScale` is a smooth asymptote of catches landed; thrashing gets
  fiercer forever.
- **Varied structure** — six named **temperaments** (Minnow · Steady · Darter · **Sunfish**
  the greed window · Diver · The Leviathan), `minStage`-gated so climbing the stages opens
  the pool; every catch (and every schedule refill) starts calm — the frame-one guard.
- **Stage arc** (Ripple → Current → Undertow → Riptide → Maelstrom) + a **secret The Deep**
  stage, revealed only by reaching it.
- **Meta** (`reel.meta`: lifetime catches/points/hauls + best stage/mult + 13 badges,
  run-report) — legacy `reel.best` preserved — and a **Glimmer** coin fun mode (1 coin,
  additive bioluminescent render only, score untouched).

Pure `tick(g, holding)`-split core + 32 tests. Collection green. Wired into the landing
(`_games/reel.md` → card + count), the README table (`gen:readme`), and the changelog.

## v0.27.4 — 2026-08-02 — GROW: Tether earns a cross-run unlock (Windfall)

**Tether gets the collection's first _cross-run unlock_** — the varied-structure standard's
rule #3 (the meta layer *driving* variation) made real, and the "grow" target chosen as the
least-recently-touched core (untouched since it was planted at v0.21.0). A new anchor-line,
**Windfall**, is absent from the pool until the player has banked **`UNLOCK_WHIPS` (150) whips
across all their runs**, then starts appearing in every deep run thereafter. It gates on
*whips* — the game's skill act — so the reward is tied to mastering the swing, not merely
surviving; skill-safe (a harder line to read, never a power boost) and **announced on the
game-over card** the run it's earned. Windfall itself is a downhill plunge: anchors drop from
the ceiling to the floor of the sky, ropes shorten and arcs quicken with every catch, so there
is no rhythm to lean on — the mirror of the calm Rise, run fast.

Pure-core changes: a new `buildWindfall`, an `unlock(meta)` predicate on the formation, and two
new pure exports — `unlockedFormations(cfg, meta)` (the earned gated ids) and
`newlyUnlockedFormations(prev, next, cfg)` (what to announce). `pickFormation` takes an optional
`unlocked` set (default none → gated formations never appear, so every prior call is unchanged);
`createGame` seeds `g.unlocked` from `opts.meta`; the shell refreshes it each run and leads the
game-over badge list with a warm-accented "New line: Windfall" notice. **+6 pure-core tests
(32 → 38):** unlock absent-until-earned, monotonic-and-not-free, `pickFormation` gating +
determinism + minStage still holds, the announce-once boundary, Windfall spawns stay
reachable/on-field, and `createGame` reads the meta. Player-facing changelog entry prepended to
`_data/changelog.json`; Tether's card `updated` bumped to today. Collection **789/789** green.
