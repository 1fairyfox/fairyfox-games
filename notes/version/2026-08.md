## v0.27.4 — 2026-08-02 — GROW: Tether earns a cross-run unlock (Windfall)

**Tether gets the collection's first _cross-run unlock_** — the varied-structure standard's
rule #3 (the meta layer *driving* variation) made real, and the "grow" target chosen as the
least-recently-touched core (untouched since it was planted at v0.21.0). A new anchor-line,
**Windfall**, is absent from the pool until the player has banked **`UNLOCK_WHIPS` (150) whips
across all their runs**, then starts appearing in every deep run thereafter. It gates on
*whips* — the game's skill act — so the reward is tied to mastering the swing, not merely
surviving; skill-safe (a harder line to read, never a power boost) and **announced on the
game-over card** the run it's earned. Windfall itself is a downhill plunge: anchors drop from
the ceiling to the floor of the sky, ropes shorten and arcs quicken with every catch, so there
is no rhythm to lean on — the mirror of the calm Rise, run fast.

Pure-core changes: a new `buildWindfall`, an `unlock(meta)` predicate on the formation, and two
new pure exports — `unlockedFormations(cfg, meta)` (the earned gated ids) and
`newlyUnlockedFormations(prev, next, cfg)` (what to announce). `pickFormation` takes an optional
`unlocked` set (default none → gated formations never appear, so every prior call is unchanged);
`createGame` seeds `g.unlocked` from `opts.meta`; the shell refreshes it each run and leads the
game-over badge list with a warm-accented "New line: Windfall" notice. **+6 pure-core tests
(32 → 38):** unlock absent-until-earned, monotonic-and-not-free, `pickFormation` gating +
determinism + minStage still holds, the announce-once boundary, Windfall spawns stay
reachable/on-field, and `createGame` reads the meta. Player-facing changelog entry prepended to
`_data/changelog.json`; Tether's card `updated` bumped to today. Collection **789/789** green.
